## ERD diagram:
### Relationships:
**A.** a *User* can own many *Project*s, but a *Project* can only be owned by one *User*<br>
**B.** a *User* can make many *Update*s, but an *Update* can only belong to one *User*<br>
**C.** a *Project* can have many *Update*s, but an *Update* can only belong to one *Project*<br>

### Table Columns
**objectId**s are automatically generated by mongoDB

| **USER**    |
|-------------|
| username    |
| password    |
| *object-id* |

---

| **PROJECT**   |
|---------------|
| title         |
| description   |
| status        |
| owner-id      |
| contributors  |
| *object-id*   |

- *owner* objectId of a *USER*
- *contributors*
  - either a list of objectIds of *USER*s
  - or a lookUp on the *UPDATE* table with either project or contributor id set
---

| **UPDATES**    |
|----------------|

| description    |
